# 🎓 Student Freelancing Platform

> A collaborative platform where students work solo or form teams to complete real-world projects for startups.

## 💡 The Problem

Students have skills but little real-world experience, and startups need affordable help. This platform connects the two: startups post projects, and students take them up alone or as a team.

## ✨ Features

- 📝 Startups can post projects
- 🙋 Students can apply solo or form teams
- 🔗 Frontend connected to real backend API calls

## 🛠️ Tech Stack

| Layer | Tools |
|-------|-------|
| Frontend | HTML, CSS, JavaScript |
| Backend | Node.js |

## 📁 Project Structure

```
student-freelancing-platform/
├── backend/        # Server, routes, database logic
├── frontend/       # UI pages and scripts
└── package-lock.json
```

## 🚀 Run Locally

```bash
# 1. Clone
git clone https://github.com/aishwarya634/student-freelancing-platform.git
cd student-freelancing-platform

# 2. Backend
cd backend
npm install
# create a .env file with your own secrets
npm start

# 3. Frontend
# open frontend/index.html in your browser
```
